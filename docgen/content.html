DexLang

A statically-typed language that compiles to C. Fast builds, native binaries, built-in HTTP/WebSocket servers, JSON serialization, database access, and concurrency.

Getting Started

Prerequisites

RequirementPurposeInstall
Go (1.21+)Build the DexLang compilergo.dev/dl or brew install go
gcc / ccCompile generated C code to native binariesXcode CLI tools (macOS) or apt install gcc (Linux)

Go and a C compiler are needed for development. For deployment, the compiled binary is a standalone native executable — no runtime dependencies. You can also use Docker (see below).

Installation

git clone https://github.com/ensamuel7/dex.git
cd dex
go build -o dex .

Your first program

Create hello.dx:

import "fmt"

fn main(): void {
  fmt.println("Hello, World!")
}

Build & Run

dex build hello.dx    # produces ./hello binary
dex run hello.dx      # build + run, cleans up after

After building, the binary is a standalone native executable that can be called directly:

dex build hello.dx
./hello               # run the compiled binary directly

Docker

For deployment without installing Go or a C compiler locally, use the Docker image:

# Build a .dx file inside Docker
docker run --rm -v $(pwd):/app dexlang/dex build /app/hello.dx

# Or use in a Dockerfile
FROM dexlang/dex AS builder
COPY . /app
RUN dex build /app/main.dx -o /app/server

FROM debian:bookworm-slim
COPY --from=builder /app/server /usr/local/bin/server
CMD ["server"]

Variables

Variables are declared with let. You can provide an explicit type annotation or let the compiler infer it:

// Explicit type annotation
let x: int = 42
let name: string = "hello"
let flag: bool = true
let nums: int[] = [1, 2, 3]

// Type inference — the type is determined from the right-hand side
let y = 100          // inferred as int
let pi = 3.14        // inferred as double
let msg = "world"    // inferred as string
let ok = true        // inferred as bool

Type inference does not work with empty array literals — these require an explicit type:

let items: int[] = []   // explicit type required

Assignment

A variable must be declared with let before it can be assigned.

x = 20
name = "DexLang"

Compound Assignment & Increment

x += 5    // equivalent to x = x + 5
x -= 2    // equivalent to x = x - 2
x++       // equivalent to x = x + 1
x--       // equivalent to x = x - 1

These operators work on numeric variables (int, long, double).

Functions & Control Flow

Functions

Functions are declared with fn or function. Both are equivalent:

fn add(a: int, b: int): int {
  return a + b
}

function main(): void {
  fmt.println("hello")
}

Control Flow

if / else

if (x > 0) {
  fmt.println(x)
} else {
  fmt.println(0)
}

else if chains are supported. The condition must be bool and enclosed in parentheses.

while

let i: int = 0
while (i < 10) {
  fmt.println(i)
  i = i + 1
}

for

C-style for loop with init, condition, and post statements:

for (let i: int = 0; i < 10; i++) {
  fmt.println(i)
}

// Type inference works in the init statement
for (let i = 0; i < 100; i += 2) {
  // iterate by 2
}

The post statement supports ++, --, +=, -=, or =.

foreach

Iterate over array elements:

let nums: int[] = [10, 20, 30]

// Value only
foreach (nums as n) {
  fmt.println(n)
}

// Index and value
foreach (nums as i, n) {
  fmt.println(i)  // 0, 1, 2
  fmt.println(n)  // 10, 20, 30
}

The iterable must be an array type. The index variable (if used) is always int. The value variable takes the element type of the array.

break and continue

Exit a loop early with break, or skip to the next iteration with continue:

while (true) {
  if (done) { break }
}

for (let i = 0; i < 10; i++) {
  if (i % 2 == 0) { continue }
  fmt.println(i)  // prints odd numbers only
}

break and continue work inside while, for, and foreach loops. Using them outside a loop is a compile error.

switch

Multi-way branching on a value. Supports int, string, char, long, double, and bool tag types. Multiple values per case are separated by commas. There is no fallthrough — only the matched case executes.

switch (action) {
    case "start": {
        fmt.println("starting")
    }
    case "stop", "pause": {
        fmt.println("not running")
    }
    default: {
        fmt.println("unknown")
    }
}

// Integer switch
switch (code) {
    case 200: {
        fmt.println("OK")
    }
    case 404: {
        fmt.println("Not Found")
    }
    default: {
        fmt.println("Other")
    }
}

Optional Types

Append ? to any type to make it optional. Optional types can hold either a value of the inner type or null.

let x: int? = 5        // has a value
let y: int? = null      // no value
let z: int?             // defaults to null
let s: string? = null   // optional string

Available Optional Types

TypeDescription
int?Optional integer
long?Optional long integer
double?Optional double
bool?Optional boolean
string?Optional string
char?Optional character

Null Checks & Type Narrowing

Use == null or != null to check if an optional has a value. Inside an if block guarded by a null check, the variable is automatically narrowed to the inner (non-optional) type.

let x: int? = 5
if (x != null) {
    // x is narrowed to int here
    let y: int = x + 1
}

Functions with Optional Types

Functions can accept and return optional types:

fn findUser(id: int): string? {
    if (id == 1) {
        return "Alice"
    }
    return null
}

fn greet(name: string?): void {
    if (name != null) {
        fmt.println(name)
    }
}

Rules

RuleExample
null can only be assigned to optional typeslet x: int = null — compile error
A value of T can be assigned to T?let x: int? = 42 — OK (automatic wrapping)
Double-optional types are not allowedlet x: int?? = null — compile error
No force-unwrap operatorUse null checks for safe access

Constants

Declare immutable variables with const. Constants cannot be reassigned, incremented, decremented, or modified with compound assignment after initialization.

const pi = 3.14
const max_size: int = 100
const name: string = "DexLang"

const supports the same syntax as let — both explicit type annotations and type inference work.

Immutability

Attempting to modify a const variable is a compile error:

const x = 42
x = 10        // ERROR: cannot reassign const variable 'x'
x++           // ERROR: cannot modify const variable 'x'
x += 5        // ERROR: cannot modify const variable 'x'

Access Modifiers

Functions, structs, and struct fields can be marked public or private. By default, all functions and structs are public — the public keyword is optional and exists only for explicitness.

Functions

// Public by default

    return 42
}

// Explicit public (same as default)
public fn also_public(): int {
    return 42
}

// Private — restricted access
private fn internal_helper(): int {
    return 99
}

Structs and Fields

Structs are public by default. Individual fields can be marked private:

struct User {
    name: string
    private password: string
}

    debug: bool
}

StringBuilder

StringBuilder is a built-in type for efficiently building strings via a growable buffer. It avoids the O(n²) cost of repeated string concatenation in loops. No import is needed.

Creating a StringBuilder

let sb = StringBuilder()
sb.append("hello ")
sb.append(42)
let result: string = sb.toString() // "hello 42"

StringBuilder Methods

MethodDescriptionReturns
.append(value)Append a value (string, int, long, double, bool, or char)void
.toString()Build the final string from the bufferstring
.len()Get the current length of the bufferint
.clear()Reset the buffer to emptyvoid

Loop Pattern

The primary use case is building strings in loops without O(n²) overhead:

import "str"

let sb = StringBuilder()
for (let i = 0; i < 100; i++) {
    sb.append(str.fromInt(i))
    sb.append(",")
}
let csv: string = sb.toString()

StringBuilder is reference-counted and automatically released at scope exit.

Enums

Enums define named sets of integer constants. Variants are assigned sequential integer values starting at 0.

String Coercion

When one operand of + is a string and the other is a non-string type, the non-string operand is automatically converted to its string representation. This works for all primitive types, structs, enums, and arrays.

let n: int = 42
let msg: string = "value: " + n     // "value: 42"

let pi: double = 3.14
let s: string = "pi is " + pi       // "pi is 3.14"

let flag: bool = true
let t: string = "flag: " + flag     // "flag: true"

// Works on either side
let x: int = 10
let s2: string = x + " items"       // "10 items"

// Structs
struct Point { x: int  y: int }
let p = Point { x: 1, y: 2 }
let s3: string = "pos: " + p        // "pos: Point{x: 1, y: 2}"

Struct Declaration

Structs define composite types with named, typed fields:

  x: int

}

  name: string

Creating Instances

Create a struct instance using literal syntax with field names:

Struct Methods

Structs can have methods defined inside the struct body:

struct Point {
    x: int
    y: int

    fn sum(): int {
        return x + y
    }

    fn display(): void {
        fmt.println("Point(" + x + ", " + y + ")")
    }
}

let p = Point{x: 3, y: 4}
let total: int = p.sum()    // 7
p.display()                  // Point(3, 4)

Value & Reference Semantics

Structs are pass-by-value by default. The function receives a copy — changes inside the function do not affect the caller:

fn tryUpdate(user: User): void {
    user.name = "changed"   // modifies the local copy only
}

let u = User{name: "john", age: 25}
tryUpdate(u)
fmt.println(u.name)   // still "john"

Use &StructName in the parameter type to pass by reference. Mutations through the reference affect the original:

fn update(user: &User): void {
    user.name = "changed"   // modifies the original
}

let u = User{name: "john", age: 25}
update(u)
fmt.println(u.name)   // "changed"

The caller does not need to write & at the call site — the compiler inserts it automatically.

Primitive references

Primitives (int, long, double, bool, char) also support the & prefix for pass-by-reference:

fn increment(n: &int): void {
    n = n + 1
}

let x: int = 5
increment(x)
fmt.println(x)   // 6

Reference fields in structs

Struct fields can use &StructName to hold a reference, enabling dependency injection patterns:

struct Database {
    host: string
}

struct Service {
    db: &Database

let db = Database{host: "localhost"}

Database

The db module provides a unified interface for SQLite, PostgreSQL, MySQL, and MongoDB. The API follows a handle-based pattern: open a connection, execute statements or query rows, iterate with a cursor, and clean up.

import "db"

let conn: int = db.open("sqlite", "app.db")
db.exec(conn, "CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)")
db.exec(conn, "INSERT INTO users (name) VALUES ('Alice')")

let rows: int = db.query(conn, "SELECT id, name FROM users")
while (db.next(rows)) {
    let name: string = db.col(rows, 1)
    fmt.println(name)
}
db.free(rows)
db.close(conn)

Key=value pairs: host, user, password, dbname, port.

MongoDB

Functions

db.open(driver: string, dsn: string) -> int

Open a database connection. Returns a connection handle (≥0) on success, or -1 on error.

db.exec(conn: int, sql: string) -> int

Execute a SQL statement (INSERT, UPDATE, DELETE, CREATE, etc.). Returns the number of affected rows, or -1 on error.

db.query(conn: int, sql: string) -> int

Execute a SELECT query. Returns a result-set handle (≥0), or -1 on error.

db.next(rows: int) -> bool

Advance the cursor to the next row. Returns true if a row is available, false when finished.

db.col(rows: int, index: int) -> int|string|double|bool

Read a column value from the current row. The return type is determined by the variable's type annotation — the compiler dispatches to the correct column reader at compile time:

let id: int = db.col(rows, 0)        // reads as int
let name: string = db.col(rows, 1)   // reads as string
let score: double = db.col(rows, 2)  // reads as double
let active: bool = db.col(rows, 3)   // reads as bool

An explicit type annotation is required — let x = db.col(rows, 0) is a compile error.

db.free(rows: int) -> void

Free a result set and release its slot. Always call this after you finish iterating.

db.close(conn: int) -> void

Close a database connection and release its slot.

MongoDB Notes

MongoDB uses a document model rather than SQL. The exec function accepts a JSON command string, and query takes a collection name to return all documents.

// exec takes a JSON database command
db.exec(conn, "{\"insert\": \"users\", \"documents\": [{\"name\": \"Alice\", \"age\": 30}]}")

// query takes a collection name — returns all documents
let rows: int = db.query(conn, "users")
while (db.next(rows)) {
    // Column 0 is _id, then fields in insertion order
    let name: string = db.col(rows, 1)
    let age: int = db.col(rows, 2)
}

Limits

The runtime uses fixed-size pools: up to 16 simultaneous connections and 64 active result sets. Always call db.free(rows) and db.close(conn) to release slots.

Concurrency

DexLang provides lightweight concurrency with four primitives: spawn, send, receive, and channel. Under the hood these compile to pthreads and a lock-free channel implementation.

spawn

Launch a concurrent task. Returns a task handle that can be used with receive to get results.

Block form

Run arbitrary code in a new thread. Use send(value) to return a result to the caller.

let task = spawn {
    let result = expensive_computation()
    send(result)
}
let val = receive(task)

Function call form

Spawn a single function call. The function's return value is automatically sent back.

fn compute(n: int): int {
    return n * 2
}

let task = spawn compute(21)
let val = receive(task)  // 42

Fire-and-forget

If you don't need the result, omit the assignment. The task runs in the background.

spawn { do_background_work() }

send

Send a value from inside a spawn block, or to a shared channel.

send(value)            // send to the task's implicit handle
send(channel, value)   // send to a shared channel

Inside a spawn block, send(value) delivers the value to whoever calls receive(task). With two arguments, send(channel, value) pushes a value into a shared channel for many-to-one communication.

receive

Block until a value is available from a task handle or channel, then return it.

let val: int = receive(task)      // receive from a task handle
let val: int = receive(channel)   // receive from a channel

The return type matches the type that was sent. For task handles, this is determined by the send(value) call or the spawned function's return type.

channel

Create a shared channel for many-to-one communication. Takes a type argument specifying the element type.

let ch = channel(int)

Channels are typed — a channel(int) can only carry int values. Use explicit type annotations with chan:

let ch: chan int = channel(int)

close

Close a channel. Subsequent sends are ignored and blocked receivers get zero values.

close(ch)

Patterns

1-to-1 (task sends result to parent)

let task = spawn {
    send(42)
}
assert(receive(task) == 42)

Many-to-one (fan-in via shared channel)

let ch = channel(int)
for (let i = 0; i < 10; i++) {
    spawn { send(ch, i * 10) }
}
let total = 0
for (let i = 0; i < 10; i++) {
    total += receive(ch)
}

Variable capture

Spawn blocks automatically capture variables from the outer scope by value. Mutations inside the block do not affect the original variables.

let x: int = 10
let task = spawn {
    // x is captured by value — this is a copy
    send(x * 2)
}
let result = receive(task)  // 20

Error Handling

DexLang provides structured exception handling with try, catch, finally, and throw. Exceptions use the built-in Exception type.

Exception Type

Exception is a built-in struct with a single field:

// Built-in (always available, no import needed)
// struct Exception(message: string) {
//     message: string
// }

Throwing Exceptions

Use throw to raise an exception with a message:

throw Exception("something went wrong")

Try-Catch-Finally

Use try to wrap code that may throw, catch to handle exceptions, and finally for cleanup that always runs:

import "fmt"

fn main(): void {
    try {
        throw Exception("oops")
    } catch (e: Exception) {
        fmt.println(e.message)  // "oops"
    } finally {
        fmt.println("cleanup")
    }
}

Try-Finally (No Catch)

If only finally is used without catch, the exception is re-thrown after the finally block runs:

try {
    throw Exception("error")
} finally {
    fmt.println("always runs")
}
// exception propagates after finally

Cross-Function Exceptions

Exceptions propagate through function calls:

fn risky(): void {
    throw Exception("from risky")
}

fn main(): void {
    try {
        risky()
    } catch (e: Exception) {
        fmt.println(e.message)  // "from risky"
    }
}

Unhandled Exceptions

If an exception is not caught, the program prints the error message to stderr and exits with code 1.

The json module builds JSON objects using string manipulation. Each function returns a new string — JSON objects are immutable.

    active: bool

Convert a JSON string into a typed struct. The target type is determined by the variable's type annotation:

wsmodule

The ws module provides WebSocket server and client functionality using RFC 6455. It supports text frames, automatic ping/pong handling, and proper client-side frame masking.

import "ws"

Types

Conn

A WebSocket connection handle:

FieldTypeDescription
fdintSocket file descriptor
isServerint1 if server-side, 0 if client-side

Server

handleMessage

ws.handleMessage(handler: fn(ws.Conn, string): void) -> void

Register a callback function to handle incoming WebSocket messages. The handler receives the connection and the message text. Must be called before listen.

listen

ws.listen(port: int) -> void

Start the WebSocket server on the given port. This call blocks. Each incoming connection is handled on a separate thread.

Client

connect

ws.connect(url: string) -> Conn

Connect to a WebSocket server. The URL should be in ws://host:port/path format. Returns a Conn handle for sending and receiving.

send

ws.send(conn: Conn, msg: string) -> void

Send a text message on a WebSocket connection.

ws.receive(conn: Conn) -> string

Receive a text message from a WebSocket connection. This call blocks until a message is available.

ws.close(conn: Conn) -> void

Close a WebSocket connection. Sends a close frame and shuts down the socket.

Server Example

To create a WebSocket server: register handlers, then call ws.listen(port). The server accepts incoming connections automatically — each client gets a ws.Conn handle passed to your handlers.

import "ws"
import "fmt"

fn onConnect(conn: ws.Conn, path: string): void {
    fmt.println("client connected on: " + path)
}

fn onMessage(conn: ws.Conn, msg: string): void {
    fmt.println("received: " + msg)
    ws.send(conn, "echo: " + msg)  // reply to this client
}

fn onDisconnect(conn: ws.Conn): void {
    fmt.println("client disconnected")
}

fn main(): void {
    // 1. Register handlers
    ws.setProtocol("ocpp1.6")           // optional subprotocol
    ws.handleConnect(onConnect)          // called when a client connects
    ws.handleMessage(onMessage)          // called on each message
    ws.handleDisconnect(onDisconnect)    // called when a client disconnects

    // 2. Start the server (blocks)
    ws.listen(9090)
}

Client Example

To connect to an existing WebSocket server: call ws.connect(url) to get a connection handle, then use ws.send/ws.receive to communicate.

import "ws"
import "fmt"

fn main(): void {
    // Connect to a running WebSocket server
    let conn: ws.Conn = ws.connect("ws://localhost:9090")

    // Send a message
    ws.send(conn, "hello server")

    // Wait for a reply
    let reply: string = ws.receive(conn)
    fmt.println(reply)

    // Clean up
    ws.close(conn)
}

The connect function supports both ws:// (plain) and wss:// (TLS via OpenSSL).

//    "let x: int = 42" → [TokenLet, TokenIdent("x"), TokenColon, TokenIntKw, ...]

// 2. Parser: tokens → AST
//    → LetStmt{Name:"x", Type:TypeInt, Value:IntLit{42}}

// 3. Checker: type-check the AST
//    → verifies IntLit(42) matches TypeInt

// 4. Codegen: AST → C source code
//    → "int x = 42;"

// 5. C compiler: C source → native binary
//    → gcc output.c -o output
