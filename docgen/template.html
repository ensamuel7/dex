DexLang

A statically-typed language that compiles to C. Fast builds, native binaries, built-in HTTP server.

Getting Started

Installation

git clone https://github.com/ensamuel7/dex.git
cd dex
go build -o dex .

Your first program

Create hello.dx:

import "fmt"

fn main(): void {
  fmt.print("Hello, World!")
}

Build & Run

dex build hello.dx    # produces ./hello binary
dex run hello.dx      # build + run, cleans up after

CLI Commands

CommandDescription
dex build <file>Compile to a native binary

dex test [file]Run test files (*_test.dx)
dex lspStart the Language Server Protocol server

Variables

Variables are declared with let. You can provide an explicit type annotation or let the compiler infer it:

// Explicit type annotation
let x: int = 42
let name: string = "hello"
let flag: bool = true
let nums: int[] = [1, 2, 3]

// Type inference — the type is determined from the right-hand side
let y = 100          // inferred as int
let pi = 3.14        // inferred as double
let msg = "world"    // inferred as string
let ok = true        // inferred as bool

Type inference does not work with empty array literals — these require an explicit type:

let items: int[] = []   // explicit type required

Assignment

A variable must be declared with let before it can be assigned.

x = 20
name = "DexLang"

Compound Assignment & Increment

x += 5    // equivalent to x = x + 5
x -= 2    // equivalent to x = x - 2
x++       // equivalent to x = x + 1
x--       // equivalent to x = x - 1

These operators work on numeric variables (int, long, double).

Functions & Control Flow

Functions

Functions are declared with fn or function. Both are equivalent:

fn add(a: int, b: int): int {
  return a + b
}

function main(): void {
  fmt.print("hello")
}

Control Flow

if / else

if (x > 0) {
  fmt.print(x)
} else {
  fmt.print(0)
}

else if chains are supported. The condition must be bool and enclosed in parentheses.

while

let i: int = 0
while (i < 10) {
  fmt.print(i)
  i = i + 1
}

for

C-style for loop with init, condition, and post statements:

for (let i: int = 0; i < 10; i++) {
  fmt.print(i)
}

// Type inference works in the init statement
for (let i = 0; i < 100; i += 2) {
  // iterate by 2
}

The post statement supports ++, --, +=, -=, or =.

foreach

Iterate over array elements:

let nums: int[] = [10, 20, 30]

// Value only
foreach (nums as n) {
  fmt.print(n)
}

// Index and value
foreach (nums as i, n) {
  fmt.print(i)  // 0, 1, 2
  fmt.print(n)  // 10, 20, 30
}

The iterable must be an array type. The index variable (if used) is always int. The value variable takes the element type of the array.

break and continue

Exit a loop early with break, or skip to the next iteration with continue:

while (true) {
  if (done) { break }
}

for (let i = 0; i < 10; i++) {
  if (i % 2 == 0) { continue }
  fmt.print(i)  // prints odd numbers only
}

break and continue work inside while, for, and foreach loops. Using them outside a loop is a compile error.

Optional Types

Append ? to any type to make it optional. Optional types can hold either a value of the inner type or null.

let x: int? = 5        // has a value
let y: int? = null      // no value
let z: int?             // defaults to null
let s: string? = null   // optional string

Available Optional Types

TypeDescription
int?Optional integer
long?Optional long integer
double?Optional double
bool?Optional boolean
string?Optional string
char?Optional character

Null Checks & Type Narrowing

Use == null or != null to check if an optional has a value. Inside an if block guarded by a null check, the variable is automatically narrowed to the inner (non-optional) type.

let x: int? = 5
if (x != null) {
    // x is narrowed to int here
    let y: int = x + 1
}

Functions with Optional Types

Functions can accept and return optional types:

fn findUser(id: int): string? {
    if (id == 1) {
        return "Alice"
    }
    return null
}

fn greet(name: string?): void {
    if (name != null) {
        fmt.print(name)
    }
}

Rules

RuleExample
null can only be assigned to optional typeslet x: int = null — compile error
A value of T can be assigned to T?let x: int? = 42 — OK (automatic wrapping)
Double-optional types are not allowedlet x: int?? = null — compile error
No force-unwrap operatorUse null checks for safe access

Constants

Declare immutable variables with const. Constants cannot be reassigned, incremented, decremented, or modified with compound assignment after initialization.

const pi = 3.14
const max_size: int = 100
const name: string = "DexLang"

const supports the same syntax as let — both explicit type annotations and type inference work.

Immutability

Attempting to modify a const variable is a compile error:

const x = 42
x = 10        // ERROR: cannot reassign const variable 'x'
x++           // ERROR: cannot modify const variable 'x'
x += 5        // ERROR: cannot modify const variable 'x'

Access Modifiers

Functions, structs, and struct fields can be marked public or private. By default, all functions and structs are public — the public keyword is optional and exists only for explicitness.

ModifierEffect
(none)Public (default)
publicPublic (explicit, same as default)
privateRestricted to the defining module

Functions

// Public by default
fn helper(): int {
    return 42
}

// Explicit public (same as default)
public fn also_public(): int {
    return 42
}

// Private — restricted access
private fn internal_helper(): int {
    return 99
}

Structs and Fields

Structs are public by default. Individual fields can be marked private:

struct User {
    name: string
    private password: string
}

private struct InternalConfig {
    debug: bool
}

Database

The db module provides a unified interface for SQLite, PostgreSQL, MySQL, and MongoDB. The API follows a handle-based pattern: open a connection, execute statements or query rows, iterate with a cursor, and clean up.

import "db"

let conn: int = db.open("sqlite", "app.db")
db.exec(conn, "CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)")
db.exec(conn, "INSERT INTO users (name) VALUES ('Alice')")

let rows: int = db.query(conn, "SELECT id, name FROM users")
while (db.next(rows)) {
    let name: string = db.col(rows, 1)
    fmt.print(name)
}
db.free(rows)
db.close(conn)

Connection Strings (DSN)

Path to the database file. Created if it does not exist.

db.open("sqlite", "mydb.sqlite")

PostgreSQL

Standard libpq connection string with key=value pairs.

db.open("postgres", "host=localhost dbname=mydb user=postgres")

MySQL

Key=value pairs: host, user, password, dbname, port.

db.open("mysql", "host=localhost user=root password=secret dbname=mydb")

MongoDB

Standard MongoDB URI. Database name is extracted from the path.

db.open("mongo", "mongodb://localhost:27017/mydb")

Functions

db.open(driver: string, dsn: string) -> int

Open a database connection. Returns a connection handle (≥0) on success, or -1 on error.

db.exec(conn: int, sql: string) -> int

Execute a SQL statement (INSERT, UPDATE, DELETE, CREATE, etc.). Returns the number of affected rows, or -1 on error.

db.query(conn: int, sql: string) -> int

Execute a SELECT query. Returns a result-set handle (≥0), or -1 on error.

db.next(rows: int) -> bool

Advance the cursor to the next row. Returns true if a row is available, false when finished.

db.col(rows: int, index: int) -> int|string|double|bool

Read a column value from the current row. The return type is determined by the variable's type annotation — the compiler dispatches to the correct column reader at compile time:

let id: int = db.col(rows, 0)        // reads as int
let name: string = db.col(rows, 1)   // reads as string
let score: double = db.col(rows, 2)  // reads as double
let active: bool = db.col(rows, 3)   // reads as bool

An explicit type annotation is required — let x = db.col(rows, 0) is a compile error.

db.free(rows: int) -> void

Free a result set and release its slot. Always call this after you finish iterating.

db.close(conn: int) -> void

Close a database connection and release its slot.

Return Values & Error Handling

FunctionOn SuccessOn Error
openConnection handle (≥0)-1
execNumber of rows affected-1
queryResult-set handle (≥0)-1
nexttrue if row availablefalse
colColumn valueZero value (0, "", false)

MongoDB Notes

MongoDB uses a document model rather than SQL. The exec function accepts a JSON command string, and query takes a collection name to return all documents.

// exec takes a JSON database command
db.exec(conn, "{\"insert\": \"users\", \"documents\": [{\"name\": \"Alice\", \"age\": 30}]}")

// query takes a collection name — returns all documents
let rows: int = db.query(conn, "users")
while (db.next(rows)) {
    // Column 0 is _id, then fields in insertion order
    let name: string = db.col(rows, 1)
    let age: int = db.col(rows, 2)
}

Limits

The runtime uses fixed-size pools: up to 16 simultaneous connections and 64 active result sets. Always call db.free(rows) and db.close(conn) to release slots.

Concurrency

DexLang provides lightweight concurrency with four primitives: spawn, send, receive, and channel. Under the hood these compile to pthreads and a lock-free channel implementation.

spawn

Launch a concurrent task. Returns a task handle that can be used with receive to get results.

Block form

Run arbitrary code in a new thread. Use send(value) to return a result to the caller.

let task = spawn {
    let result = expensive_computation()
    send(result)
}
let val = receive(task)

Function call form

Spawn a single function call. The function's return value is automatically sent back.

fn compute(n: int): int {
    return n * 2
}

let task = spawn compute(21)
let val = receive(task)  // 42

Fire-and-forget

If you don't need the result, omit the assignment. The task runs in the background.

spawn { do_background_work() }

send

Send a value from inside a spawn block, or to a shared channel.

send(value)            // send to the task's implicit handle
send(channel, value)   // send to a shared channel

Inside a spawn block, send(value) delivers the value to whoever calls receive(task). With two arguments, send(channel, value) pushes a value into a shared channel for many-to-one communication.

receive

Block until a value is available from a task handle or channel, then return it.

let val: int = receive(task)      // receive from a task handle
let val: int = receive(channel)   // receive from a channel

The return type matches the type that was sent. For task handles, this is determined by the send(value) call or the spawned function's return type.

channel

Create a shared channel for many-to-one communication. Takes a type argument specifying the element type.

let ch = channel(int)

Channels are typed — a channel(int) can only carry int values. Use explicit type annotations with chan:

let ch: chan int = channel(int)

close

Close a channel. Subsequent sends are ignored and blocked receivers get zero values.

close(ch)

Patterns

1-to-1 (task sends result to parent)

let task = spawn {
    send(42)
}
assert(receive(task) == 42)

Many-to-one (fan-in via shared channel)

let ch = channel(int)
for (let i = 0; i < 10; i++) {
    spawn { send(ch, i * 10) }
}
let total = 0
for (let i = 0; i < 10; i++) {
    total += receive(ch)
}

Variable capture

Spawn blocks automatically capture variables from the outer scope by value. Mutations inside the block do not affect the original variables.

let x: int = 10
let task = spawn {
    // x is captured by value — this is a copy
    send(x * 2)
}
let result = receive(task)  // 20

Error Handling

DexLang provides structured exception handling with try, catch, finally, and throw. Exceptions use the built-in Exception type.

Exception Type

Exception is a built-in struct with a single field:

// Built-in (always available, no import needed)
// struct Exception(message: string) {
//     message: string
// }

Throwing Exceptions

Use throw to raise an exception with a message:

throw Exception("something went wrong")

Try-Catch-Finally

Use try to wrap code that may throw, catch to handle exceptions, and finally for cleanup that always runs:

import "fmt"

fn main(): void {
    try {
        throw Exception("oops")
    } catch (e: Exception) {
        fmt.print(e.message)  // "oops"
    } finally {
        fmt.print("cleanup")
    }
}

Try-Finally (No Catch)

If only finally is used without catch, the exception is re-thrown after the finally block runs:

try {
    throw Exception("error")
} finally {
    fmt.print("always runs")
}
// exception propagates after finally

Cross-Function Exceptions

Exceptions propagate through function calls:

fn risky(): void {
    throw Exception("from risky")
}

fn main(): void {
    try {
        risky()
    } catch (e: Exception) {
        fmt.print(e.message)  // "from risky"
    }
}

Unhandled Exceptions

If an exception is not caught, the program prints the error message to stderr and exits with code 1.

fmtmodule

The fmt module provides formatted output to stdout.

import "fmt"

print

fmt.print(value: int|long|double|string|bool) -> void

Print a single value followed by a newline. Accepts any primitive type — the compiler selects the correct format string at compile time.

fmt.print(42)            // prints: 42
fmt.print("hello")       // prints: hello
fmt.print(3.14)          // prints: 3.140000
fmt.print(true)          // prints: true
fmt.print(1000000)       // prints: 1000000

Each call prints exactly one value. To print multiple values, use multiple calls or build a string with concatenation.

jsonmodule

The json module builds JSON objects using string manipulation. Each function returns a new string — JSON objects are immutable.

import "json"

new

json.new() -> string

Create an empty JSON object. Returns the string {}.

let obj: string = json.new()  // "{}"

set

json.set(obj: string, key: string, value: string|int|bool|long|double) -> string

Set a key-value pair on a JSON object. Returns a new string with the field added. The value type is detected at compile time — no type suffix needed.

let obj: string = json.new()
obj = json.set(obj, "name", "Dex")       // string value
obj = json.set(obj, "version", 1)         // int value
obj = json.set(obj, "stable", true)       // bool value
obj = json.set(obj, "bignum", 1000000)    // long value
obj = json.set(obj, "pi", 3.14)           // double value
// {"name":"Dex","version":1,"stable":true,"bignum":1000000,"pi":3.14}

Each call inserts the new field before the closing }. The original string is not modified — you must reassign the result.

setArray

json.setArray(obj: string, key: string, arr: T[]) -> string

Set an array value on a JSON object. Works with any array type (int[], long[], double[], bool[], string[]).

let nums: int[] = [1, 2, 3]
let obj: string = json.new()
obj = json.setArray(obj, "numbers", nums)
// {"numbers": [1, 2, 3]}

stringify

json.stringify(arr: T[]) -> string

Convert an array to a JSON array string. Works with any array type.

let nums: int[] = [10, 20, 30]
let s: string = json.stringify(nums)  // "[10, 20, 30]"

let names: string[] = ["alice", "bob"]
let s2: string = json.stringify(names)  // ["alice", "bob"]

Full example

import "json"
import "http"

fn handle_api(): string {
    let scores: int[] = [10, 20, 30]
    scores.push(40)

    let obj: string = json.new()
    obj = json.set(obj, "message", "Hello from Dex!")
    obj = json.set(obj, "count", scores.len())
    obj = json.setArray(obj, "scores", scores)
    obj = json.set(obj, "success", true)
    return obj
}

fn main(): void {
    http.route("GET", "/api", "handle_api")
    http.listen(8080)
}

httpmodule

The http module provides a built-in HTTP server and a full HTTP client. Routes map HTTP methods and paths to handler functions. Client functions send requests and return HttpResponse structs.

import "http"

Server

route

http.route(method: string, path: string, handler: string) -> void

Register a route handler. The handler is referenced by name as a string literal. Handler functions must take no parameters and return string (the HTTP response body).

fn my_handler(): string {
    return "{\"ok\": true}"
}

fn main(): void {
    http.route("GET", "/api", "my_handler")
    http.listen(3000)
}

The handler name must be a string literal — it is resolved to a function pointer at compile time.

listen

http.listen(port: int) -> void

Start the HTTP server on the given port. This call blocks — it runs the server event loop indefinitely.

http.listen(8080)  // server listens on http://localhost:8080

Client

Client functions send HTTP requests and return an HttpResponse struct. Requires libcurl at compile time.

HttpResponse

All client request functions return an HttpResponse with three fields:

FieldTypeDescription
statusCodeintHTTP status code (e.g. 200, 404, 500)
bodystringResponse body content
contentTypestringContent-Type header from the response

Request Functions

http.get(url: string, [headers: string]) -> HttpResponse
http.post(url: string, body: string, [headers: string]) -> HttpResponse
http.put(url: string, body: string, [headers: string]) -> HttpResponse
http.patch(url: string, body: string, [headers: string]) -> HttpResponse
http.delete(url: string, [headers: string]) -> HttpResponse
http.request(method: string, url: string, body: string, headers: string) -> HttpResponse

The headers parameter is optional for get, post, put, patch, and delete. Use request for full control over method and headers.

// Simple GET
let resp: HttpResponse = http.get("https://api.example.com/data")
fmt.print(resp.statusCode)
fmt.print(resp.body)

// POST with JSON body
let body: string = json.new()
body = json.set(body, "name", "Alice")
let r: HttpResponse = http.post("https://api.example.com", body)

Headers

Headers can be provided in two formats:

http.header(headers: string, key: string, value: string) -> string
// JSON approach — auto-detected when string starts with {
let headers: string = json.new()
headers = json.set(headers, "Authorization", "Bearer token")
let r: HttpResponse = http.get("https://api.example.com", headers)

// Header builder approach
let h: string = http.header("", "Authorization", "Bearer token")
h = http.header(h, "Content-Type", "application/json")
let r2: HttpResponse = http.post("https://api.example.com", body, h)

Multipart Form Data

http.formNew() -> string
http.formField(form: string, name: string, value: string) -> string
http.formFile(form: string, name: string, path: string) -> string
http.postForm(url: string, form: string, [headers: string]) -> HttpResponse
let form: string = http.formNew()
form = http.formField(form, "name", "Alice")
form = http.formFile(form, "avatar", "/path/to/photo.jpg")
let r: HttpResponse = http.postForm("https://api.example.com/upload", form)

Server example

import "http"
import "json"

fn handle_hello(): string {
    return "{\"message\": \"Hello, World!\"}"
}

fn handle_json(): string {
    let response: string = json.new()
    response = json.set(response, "message", "Hello from Dex!")
    response = json.set(response, "number", 42)
    response = json.set(response, "success", true)
    return response
}

fn main(): void {
    http.route("GET", "/hello", "handle_hello")
    http.route("GET", "/json", "handle_json")
    http.listen(8080)
}

filemodule

The file module provides filesystem operations and HTTP file uploads.

import "file"

read

file.read(path: string) -> string

Read the entire contents of a file and return it as a string. Returns an empty string if the file does not exist or cannot be read.

let content: string = file.read("config.txt")
fmt.print(content)

write

file.write(path: string, data: string) -> bool

Write data to a file, creating it if it does not exist or overwriting if it does. Returns true on success.

let ok: bool = file.write("output.txt", "Hello, World!")
if (!ok) {
    fmt.print("Failed to write file")
}

append

file.append(path: string, data: string) -> bool

Append data to the end of a file. Creates the file if it does not exist. Returns true on success.

file.append("log.txt", "Event occurred\n")

exists

file.exists(path: string) -> bool

Check whether a file exists at the given path.

if (file.exists("config.json")) {
    let cfg: string = file.read("config.json")
}

remove

file.remove(path: string) -> bool

Delete a file. Returns true if the file was successfully removed.

file.remove("temp.txt")

rename

file.rename(old_path: string, new_path: string) -> bool

Rename or move a file. Returns true on success.

file.rename("draft.txt", "final.txt")

upload

file.upload(path: string, url: string) -> string

Upload a file to a URL via HTTP multipart form POST. The file is sent as a form field named file. Returns the server's response body as a string, or an empty string on failure.

let response: string = file.upload("photo.jpg", "https://api.example.com/upload")
fmt.print(response)

Requires libcurl at compile time (brew install curl on macOS).

Full example

import "file"
import "fmt"

fn main(): void {
    // Write and read back
    file.write("hello.txt", "Hello, Dex!")
    let content: string = file.read("hello.txt")
    fmt.print(content)

    // Append a line
    file.append("hello.txt", "\nSecond line")

    // Check and clean up
    if (file.exists("hello.txt")) {
        file.remove("hello.txt")
    }
}

Abstract Syntax Tree

DexLang source code is parsed into an AST defined in ast/ast.go. The compilation pipeline is: .dx source → tokens → AST → type check → C code → native binary.

Program Structure

A Program is the top-level AST node containing all imports, struct definitions, and functions.

// Program is the root of every .dx file
Program {
    Imports:   []Import    // import "fmt", import "db", ...
    Structs:   []StructDef // struct definitions
    Functions: []Function  // all function declarations
}

Compilation Pipeline

// 1. Lexer: source text → tokens
//    "let x: int = 42" → [TokenLet, TokenIdent("x"), TokenColon, TokenIntKw, ...]

// 2. Parser: tokens → AST
//    → LetStmt{Name:"x", Type:TypeInt, Value:IntLit{42}}

// 3. Checker: type-check the AST
//    → verifies IntLit(42) matches TypeInt

// 4. Codegen: AST → C source code
//    → "int x = 42;"

// 5. C compiler: C source → native binary
//    → gcc output.c -o output
